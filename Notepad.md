# Notepad – Implementation Notes

## Optional Features Chosen

### 1. Cursor Line / Column Indicator
Added to the existing status bar alongside word and line counts. The `updateCursorPosition()` slot connects to `QTextEdit::cursorPositionChanged` and reads `QTextCursor::blockNumber()` and `columnNumber()` to display the current `Ln X, Col Y` position in real time.

### 2. Font Dialog
`Format > Font...` opens Qt's built-in `QFontDialog`. If the user has a text selection, the chosen font is applied only to the selection via `QTextCursor::mergeCharFormat`; otherwise it sets the default font for new typing via `setCurrentFont`.

### 3. Color Picker
`Format > Text Color...` opens `QColorDialog`. The selected `QColor` is applied to the current selection (or insertion point) by merging a `QTextCharFormat` with a `setForeground` brush.

## Required Features

### Exception Handling
`notepad_exception.h` defines a hierarchy:
- `notepad_exception` – base class (inherits `std::runtime_error`)
- `file_not_found_exception` – thrown when the path does not exist
- `file_read_exception` – thrown when the file cannot be opened for reading
- `file_write_exception` – thrown when the file cannot be opened for writing

`open_file()` and `save_file()` are wrapped in `try / catch` blocks in the calling slots (`openFile`, `saveFile`, `saveFileAs`). Errors are displayed with `QMessageBox::critical` using the title `"Error"`.

### Spell Checker
`SpellChecker` loads `data/words.txt` into a `QSet<QString>` at startup. A word is considered misspelled if, after lowercasing and stripping non-alphabetic characters, it is not in the set.

`SpellCheckerHighlighter` (subclass of `QSyntaxHighlighter`) uses a word-boundary regex and `QTextCharFormat::SpellCheckUnderline` in red to highlight misspelled words inline as you type.

Right-clicking a misspelled word shows a `QMenu` with up to 5 suggestions generated by an edit-distance algorithm (Levenshtein distance ≤ 2). Clicking a suggestion replaces the word in the editor.

`Tools > Check Spelling...` calls `rehighlight()` to re-run the highlighter over the whole document.
